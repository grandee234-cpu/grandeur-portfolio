# Personal website

This is a static site: no paid hosting or special setup is needed.

Before publishing, edit `index.html` and replace:

- `your-email@example.com` with your email address
- The About paragraph and project cards with your details

Then upload these files to a GitHub repository and import that repository at https://vercel.com/new. Vercel will give you a free public `*.vercel.app` link and automatically update the live site whenever you update GitHub.
